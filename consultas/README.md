# Consultas

Este diretório contém queries SQL de leitura e análise de dados do negócio.

## 📁 Subdiretórios

### vendas/
Queries relacionadas ao processo de vendas:
- Relatórios de vendas por período, produto, região
- Análise de performance de vendedores
- Análise de metas e projeções
- Tendências e sazonalidade

### estoque/
Queries de gestão de estoque e inventário:
- Produtos com estoque crítico
- Movimentação de estoque
- Análise de giro de produtos
- Inventário e contagens

### financeiro/
Queries do setor financeiro:
- Contas a pagar e receber
- Fluxo de caixa
- Conciliação bancária
- Análise de inadimplência

### relatorios/
Relatórios gerenciais e dashboards:
- KPIs do negócio
- Relatórios executivos
- Consolidações
- Análises comparativas

### manutencao/
Queries para manutenção e limpeza de dados:
- Identificação de inconsistências
- Correção de dados
- Validações
- Purgas e arquivamentos

## 💡 Como Usar

1. Navegue até o subdiretório apropriado
2. Escolha a query que atende sua necessidade
3. Leia a documentação no cabeçalho do arquivo
4. Ajuste os parâmetros conforme necessário
5. Execute em seu cliente SQL preferido

## ⚠️ Importante

- Sempre teste queries em ambiente de desenvolvimento primeiro
- Substitua os parâmetros `:variavel` pelos valores reais
- Verifique se você tem as permissões necessárias nas tabelas
- Considere o impacto de performance em tabelas grandes
